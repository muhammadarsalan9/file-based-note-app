# 📝 File-Based Notes App (Java)

A simple console-based Notes Application built using Java that allows users to store and retrieve notes using file handling.

---

## 🚀 Features

* Add notes
* Read saved notes
* Persistent storage using file system
* Menu-driven CLI

---

## 🛠️ Tech Stack

* Java
* File Handling (BufferedReader, BufferedWriter)

---

## ▶️ How to Run

1. Clone repo:

```
git clone https://github.com/muhammadarsalan9/file-based-note-app.git
```

2. Open in IntelliJ
3. Run `Main.java`
